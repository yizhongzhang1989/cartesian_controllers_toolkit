Motion controller: snapshots current pose on engage, then rigidly drives the end-effector to whatever target you publish. Each jog press computes new_target = current_EE_pose + delta in base_link and publishes it on /cartesian_motion_controller/target_frame. Snap resets the target to the current pose.
Compliance controller (spring-hold): on engage the controller snapshots the current end-effector pose as its target. With target_wrench=0 (published by the orchestrator) and the configured stiffness, pushing the end-effector makes it yield; release and it springs back to the held pose. Use Re-snap hold pose after drift to re-anchor the spring at the current pose. Tune the stiffness.* rows in “Parameters” below to change how stiff the spring is — higher = stiffer. Jog presses move the held pose by an incremental delta.
